# VROOQ — Initial Source Audit (21 November 2026)

**Scope:** Source inspection of `indepadib/Crankd` at `main`. Architecture: Next.js 16 web app, Expo mobile client, Supabase data/auth/edge functions, Netlify config. This is NOT a live penetration test, a browser visual audit, or a verified production database assessment.

**Live-site limitation:** `https://vrooq.ma` could not be loaded through the available environment. A separately indexed `vrooq.com` exists, but the domain mapping to this repo or live production has not been proven. Confirm domains and Netlify deploy configuration before SEO changes.

## P0 — Security/data integrity

1. **Unsafe RLS in `INIT_DATABASE.sql`.** `post_comments` accepts anonymous inserts; `listings` policy allows inserts without checking `seller_id = auth.uid()`; `maintenance_logs` allows inserts without linking to an owned vehicle. A row's alleged owner/author cannot be trusted without a matching policy. Inspect the actual live policies before applying a corrective migration.
2. **Ownership transfer function is incomplete.** `backend/functions/transfer-ownership/index.ts` generates 6-character tokens with `Math.random()` and has a TODO instead of checking seller ownership before issuance. Its service-role configuration requires an explicit trust-boundary review. Do not enable the current function for live transfer.
3. **Receipt 'verification' is simulated.** `backend/functions/ingest-receipt/index.ts` returns hardcoded vendor, amount, line items and 0.98 confidence, then stores an automatically verified log. Disable such verification claims in any production-exposed route until a real extraction and human-review process exists.
4. **Payment flow is simulated.** `backend/functions/create-payment-intent/index.ts` returns a `pi_mock_*` secret, not an actual Stripe payment intent. Never describe premium purchase as completed.
5. **Browser-only route protection.** `web/middleware.ts` currently does nothing; `web/app/(app)/layout.tsx` renders app chrome without a server authorization guard. RLS must protect all sensitive data even if a route is visible; introduce authenticated SSR and protected mutations before storing sensitive content.

## P1 — Activation and trust

6. **Recovery link dead.** `web/app/(auth)/login/page.tsx` links `Forgot?` to `#`. First PR adds recovery request and reset screens. Requires Supabase Auth redirect allowlist configuration.
7. **Signup confirmation mismatch.** `web/app/(auth)/signup/page.tsx` always redirected to `/feed` after two seconds, even when Supabase required email verification. First PR corrects that.
8. **Demo posts are indistinguishable from real posts.** `web/hooks/useFeed.ts` populates `localStorage` with automotive example posts and fabricated engagement counts. Separate explicit demo mode from real activity, or remove before production launch.
9. **Several social interactions are local-only.** For example, feed RSVP uses localStorage in `web/components/Feed.tsx`. A user signing in on another device will not see the same participation.
10. **Potential legal links unresolved.** `web/app/(auth)/layout.tsx` links both Privacy and Terms to `/terms`; no route exists in the checked repository tree. Do not publish invented legal terms; obtain approved texts and create dedicated routes.

## P2 — Sustainable growth and design

11. **Multiple large components.** `web/app/(app)/garage/page.tsx` (~162 KB), `web/app/(app)/create/page.tsx` (~76 KB) and `web/components/Feed.tsx` (~49 KB) should be split by feature, data fetching, and presentation.
12. **Conflicting SQL starting points.** `backend/schema.sql`, `backend/00_setup_v1.sql`, and `INIT_DATABASE.sql` describe divergent table structures. A single migration history and schema diff are needed.
13. **Market/localization is undecided.** Landing page showcases fictional/inventory-style international cars, English-only copy, USD prices. Confirm launch country, audience, marketplace purpose, and primary conversion before an expensive redesign.
14. **Quality evidence is thin.** `web/package.json` has dev/build/lint scripts but no test script. No CI workflow was found in the inspected Git tree. Add a baseline smoke test and report failures before scaling features.
